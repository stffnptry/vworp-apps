# vworp apps

Kleine, native macOS-Apps (Apple Silicon). Landingpage: https://stffnptry.github.io/vworp-apps/

Downloads: [Releases](https://github.com/stffnptry/vworp-apps/releases/latest)

Die Apps sind ad-hoc signiert (nicht notarisiert): beim ersten Start per Rechtsklick → Öffnen starten.

STLFixer enthält [MeshFix](https://github.com/MarcoAttene/MeshFix-V2.1) (GPL-3.0) und [ADMesh](https://github.com/admesh/admesh) (GPL-2.0).
